Skips all permission checks and approval prompts inside the agent, allowing it to execute tools (file edits, shell commands, etc.) without confirmation. Use with caution — the agent will have unrestricted access to the workspace. For Pi Coding Agent, YOLO enables the default tools and trusts project-local configuration. With YOLO off, only read, grep, find, and ls are enabled and project-local configuration is ignored. This is not an OS sandbox; trusted Extra args or extensions can override tool selection.
