Optional file path, relative to the workspace root, that receives a copy of the raw agent log after the agent process exits. Leave empty to keep the log only on the build page. The path does not depend on Working directory.

The file contains the same lines as the raw log on the build page: agent stdout and stderr, one line per entry, with the injected API key credential masked. Other secrets the agent reads or prints are not masked. An existing file at the path is removed before the agent starts and replaced after it exits, so use a distinct path for each invocation, for example ai-logs/${BUILD_NUMBER}-review.jsonl. Environment variables are expanded, and both / and \ separate directories.

The copy is also attempted when the agent fails, times out, or the build is aborted. If the copy fails, the build fails; when the step already failed with an error, such as an abort, the copy failure is logged and attached to that error. Absolute paths, .. segments, and parent directories that resolve outside the workspace through symlinks are rejected. A symlink, FIFO, or file at the target path is removed and the log is written to a newly created file.

Archive or ship the file with later steps, for example archiveArtifacts or an upload to your log storage.
